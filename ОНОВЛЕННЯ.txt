ОНОВЛЕННЯ iPhone / PWA (версія 2)
1. Відкрийте репозиторій з GitHub Pages -> Add file -> Upload files.
2. Перетягніть index.html та sw.js з цієї папки (вони замінять старі). Інші файли (іконки, manifest) не змінювались — можна не вантажити.
3. Commit changes. Через 1-2 хвилини оновиться сайт.
4. На iPhone відкрийте додаток з інтернетом; якщо ще стара версія — закрийте його повністю і відкрийте знову (у sw.js кеш піднято до pdr-v3).
