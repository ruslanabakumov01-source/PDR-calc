# PDR Калькулятор: версія для GitHub Pages (PWA)

Усі файли цієї папки кладуться в КОРІНЬ публічного репозиторію GitHub:
`index.html`, `manifest.webmanifest`, `sw.js`, `icon-*.png`, `apple-touch-icon.png`, `.nojekyll`.

## Як опублікувати (безкоштовно)
1. github.com → **New repository**. Назва, наприклад, `pdr-calc`. Тип **Public** (для безкоштовних Pages потрібен публічний).
2. **uploading an existing file** → перетягніть усі файли цієї папки (прихований `.nojekyll` теж, якщо його видно) → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, папка `/(root)` → **Save**.
4. Через 1–2 хвилини зверху з'явиться посилання виду `https://ВАШ-ЛОГІН.github.io/pdr-calc/`. Це і є адреса калькулятора.

## Як це ставлять люди
- **iPhone (Safari):** відкрити посилання → кнопка «Поділитися» → **На екран “Додому”**.
- **Android (Chrome):** відкрити посилання → меню ⋮ → **Встановити додаток** (або «Додати на головний екран»).
Після першого відкриття калькулятор працює і без інтернету.

## Як випустити оновлення
Замініть `index.html` на нову версію і в `sw.js` збільште номер: `const CACHE = 'pdr-v2';` (потім v3, v4...).
У людей нова версія з'явиться при наступному відкритті з інтернетом.

Дані (оцінки, фото, історія) зберігаються лише на телефоні кожного користувача.
